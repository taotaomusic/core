# 桃桃音乐 True-VMP 类前缀清单
#
# 每行一个 Dalvik 类型描述符前缀，传给 XopProtector 的 --true-vmp-prefix。
# 匹配规则是 typeDescriptor.startsWith(prefix)：
#   - 不以分号结尾时，会同时覆盖该类的嵌套类 / Kotlin 合成类 / suspend 状态机。
#   - 以分号结尾时只匹配该类本身，用于方法数特别大、嵌套 DTO 特别多的类。
#
# 约束：
#   - 只允许业务逻辑层（data/、player/、model/）的核心类。
#   - 禁止 ui/、playerui/、hotfix/、update/、data/db/、data/im/、crypto/（传输层加密）。
#     data/crypto/ 仅 HardwareDeviceId 例外，它只做设备标识派生，不碰 JNI 传输层。
#   - 禁止组件类（如 com.taotao.music.player.PlaybackService），VMP 不跳过组件。
#   - 新增核心业务类后必须同步本文件，否则加固报告里的 TRUE_VMP 数量会下降。
#
