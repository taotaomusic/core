# 动效与渲染性能优化计划

本目录记录 2026-08-24 对桃桃音乐 Android 端完成的动效审计与执行方案。方案遵循项目现有 `AnimationTheme.kt` 集中式规范，并优先保证播放页与歌词页的帧稳定性。

001–004 属于动效与渲染优化；005 起为架构与音源接入类方案，沿用同一套编号与状态约定。

| 编号 | 方案 | 严重度 | 状态 | 依赖 |
| --- | --- | --- | --- | --- |
| 001 | 隔离歌词帧级状态 | 高 | DONE | 无 |
| 002 | 收紧页面层级与高频导航动效 | 高 | DONE | 无 |
| 003 | 精简高频控件与搜索结果动效 | 中 | DONE | 002 的动效 token |
| 004 | 补齐状态过渡与无障碍语义 | 中 | DONE | 001、002 |
| 005 | 客户端业务模块化迁移 | 高 | TODO | 无 |
| 006 | 接入酷我「波点」音源 | 中 | TODO | 005 不阻塞，但需先抽音源分派 |

推荐顺序为 001 → 002 → 003 → 004：先消除逐帧重组压力，再统一页面运动语言，之后收紧高频控件，最后完善较少使用的状态切换和辅助功能体验。

## 执行结果

- 歌词帧级播放位置仅由当前逐字行读取；非当前行不再随每帧重组，且所有歌词行保持相同高度。
- “音乐 / 我的”、播放 / 暂停、搜索结果列表等高频路径改为即时响应；详情与面板等低频层级路径保留短促的 transform/opacity 过渡。
- 搜索异步状态使用 Android Compose 语义树的 `liveRegion`，歌词跳转动作提供明确标签；Compose 动效继续跟随系统动画时长设置。
- 每次 Release 都以 `output-metadata.json` 为唯一版本来源，并在签名校验后交付 APK。
